# rollback-gate

**动之前，先把三句话写下来。**

一道很土的闸：它拦不住你，但它会**留下一张纸**。

---

## 为什么有它

我删掉过一个正在用的目录。跑之前，没有任何人看过。

纸上其实早写全了：先写三问、回滚不许依赖已被破坏的东西、要有第二双眼睛。
**可它一直是纸 —— 我随时可以直接跑。** 四天后，同样的命令又从那张纸底下溜过去了。

⇒ 结论：**靠"我记得"没用，得把流程变成必跑的步骤。**

## 它是什么 / 不是什么

**是**：一条必经的流程 ＋ 一张送到审批人手上的单 ＋ 一份带原话的留痕。
**不是**：物理闸。**能绕过**（直接敲 bash 就行）。

它值钱的地方在这里：

> **一旦绕过，纸上就断链、审批人那边就少一条 —— 这是能事后查出来的。**
> 而"我保证我记得"查不出来。

判据很土：**走它的成本是三十秒；绕过它的代价，是把上次那件事再经历一遍。**

## 三问（缺一个不收）

| 参数 | 要写什么 |
|---|---|
| `--what` | 要做什么（**具体动作**，不是意图） |
| `--fail` | 失败长什么样 / 怎么发现 |
| `--rollback` | 回滚靠什么 |

⚠ 回滚的判据：**假设目标已经彻底坏掉，这条回滚还能不能执行？** 不能 ⇒ **这条回滚不算数**。
（典型反例：「坏了就 `cp` 回来」—— 如果备份和正本在同一块盘、同一次误操作能一起没，它就不算回滚。）

## 用法

```bash
# 1) 建单（会推给审批人，并写一张 <dir>/<id>.md）
node gate.mjs ask "要动什么" --what "具体动作" --fail "坏了怎么发现" --rollback "怎么退回去"

# 2) 记下点头 —— 必须是审批人真的说过的话
node gate.mjs ok <id> "<原话>"

# 3) 跑（三问齐 + 已点头，才放行）
node gate.mjs run <id> -- <命令>

# 看状态
node gate.mjs list

# 只问"这条命令算什么级别"
node gate.mjs level "rm -rf /srv/app"
node gate.mjs check "docker restart web"

# 自检（判据 + 端到端，全程在临时目录里跑）
node gate.mjs selftest
```

## 分级

| 级别 | 什么算 | 怎么办 |
|---|---|---|
| `L0` 读 | `ls` / `cat` / `grep` / `git log` … | 随便做，不问不记 |
| `L1` 普通写 | 没命中危险判据的写 | 直接做，留一行痕 |
| `L2` 动现役 | 命中你自己配的规则 | 建单写三问、跑完记结果 |
| `L3` 危险 | 命中 `l3` 那组（默认：`rm -rf` / 重启容器 / 停服务） | **必须有人点头**：`ask` → `ok` → `run` |

⚠ **只读逃逸是故意的**：只读命令不拦。**不然闸会变成天天叫的噪音 —— 而噪音等于没人用。**

## 配置 `gate.config.json`（可选）

```json
{
  "dir": "./gate",
  "rules": [
    { "re": "你的危险路径", "why": "为什么要拦它" },
    { "re": "\\bsome-deploy-script\\b", "why": "会覆盖现役" }
  ],
  "l3": ["\\brm\\s+(-[a-zA-Z]*\\s+)*-?[a-zA-Z]*[rf]", "重启类命令的正则"],
  "notify": { "kind": "off" }
}
```

- **默认 `notify.kind = "off"`** —— 不配就**什么都不发**（它不会偷偷替你连网）。
- `"kind": "webhook"` ＋ `"url": "https://…"`：POST 一个 JSON `{title, body}`。
- `"kind": "cmd"` ＋ `"cmd": "…"`：把 JSON 从 stdin 喂给你自己的脚本（想接什么接什么）。

## 已知边界（别拿它当安全边界）

- **它是提示器，不是沙箱。** `node -e "fs.rmSync(…)"` 这种只有列了删除 API 才拦得住。
- 判据表是**正则**，能骗过去。它的目的从来不是"拦住懂行的人"，而是**在动手前逼出一张纸**。
- `run` 只校验"三问齐 ＋ 有原话"，**不校验命令合理** —— 那是人该看的事。
